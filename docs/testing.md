# Testing

This page used to hold a release checklist written for the Audio Hijack
recorder, which MeetingNotes no longer uses. The current material is:

- [Manual smoke test](manual-smoke-test.md) — the hands-on checklist to run before a release.
- [Local CI on Tart](local-ci.md) — the automated suite, its quick and full tiers, and what each covers.
- `npm test` runs the unit and integration suite; `npm run smoke:source` launches the built app against a synthetic library.
