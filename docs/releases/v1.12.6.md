# MeetingNotes 1.12.6

**Release date:** 2026-09-25

This update makes new, ungrouped meetings easier to spot and group moves harder to make by accident. It includes the group-move improvements that were previously available only in a local 1.12.5 installer. There was no 1.12.5 GitHub release. The 1.12.6 GitHub release is source-only; the Apple Silicon installer is built locally and is not attached to GitHub.

## Highlights

### Ungrouped first

- The organized Library now puts **Ungrouped** at the top, ahead of alphabetically sorted named groups. New recordings that have not been assigned to a group are immediately visible there.
- Grouped search results use the same order. Ungrouped still starts expanded on first use, and existing expand/collapse choices remain intact.
- The flat **All meetings** view, group assignments, and ordering of meetings *within* each section are unchanged.

### Safer moves between groups

- Moving an existing meeting now shows its title and current group, requires choosing a destination, and waits for an explicit **Move to …** confirmation. Bulk moves show a preview and warn when the selection includes meetings outside the visible list.
- Searching for a destination clears the previous choice; a single meeting cannot be moved to its current group. Errors and the selected destination are shown in the dialog.
- Completed bulk moves clear from selection. Meetings that could not be moved stay selected for retry, with the outcome shown in the toast. Successful moves retain **Undo**.
- **Create and move** remains a clearly labeled single action after entering a new group name.

## Upgrade and rollback

- Requires macOS 14.2+ on Apple Silicon. Back up the meeting library before upgrading and retain your earlier installer if you may need to roll back.
- No database migration, audio-file move, capture change, processing change, or remote service is introduced. Groups remain organizational metadata; deleting or moving a group assignment does not alter audio or notes.
- Rolling back to 1.12.4 restores its earlier group-move interaction and Ungrouped-last presentation without changing group assignments. Local expansion preferences remain compatible.

## Verification

- Production TypeScript/Vite build and targeted ESLint for the changed ordering code passed. The full Vitest suite passed: 121 files and 934 tests, with 2 opt-in files and 6 tests skipped.
- The test suite required rebuilding `better-sqlite3` for Node after an installer build; the Electron ABI was restored and verified afterward. This was an environment adjustment, not a product-code fix.
- The new ordering test verifies Ungrouped first with named groups alphabetic. Existing tests cover grouped search bucketing and persisted expansion preferences.
- A live recording and full visual smoke test against the user's meeting library were not performed; no active capture or processing workflow was interrupted.

## Build locally

```bash
git clone https://github.com/dbbaskette/MeetingNotes.git
cd MeetingNotes
git checkout v1.12.6
npm install
npm run dist
```

Expected outputs: `release/MeetingNotes-1.12.6-arm64.dmg` and `release/MeetingNotes-1.12.6-arm64-mac.zip`. Verify the local artifact's version, signature, and checksum before distributing it. GitHub does not carry these binaries.

## Known limitations

- The local app uses an Apple Development certificate. Apple notarization is not configured, so the installer is not claimed as notarized.
- A meeting can belong to only one group. Groups do not have nesting, manual pinning/reordering, or drag-and-drop assignment.
- Expanding a group loads its first page; deeper meetings require **Load more**. The production renderer still lacks a Content Security Policy.
