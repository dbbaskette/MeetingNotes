# MeetingNotes 1.19.2 — Obsidian vault availability

Fixes Obsidian sync reporting “Vault is unavailable or was replaced” for an
existing, correctly configured vault after a reboot or remount changes its disk
device number. This also fixes preview rejecting the same valid destination.

Recovery requires both the original vault and managed sync folder to retain
their folder IDs, a consistent device-number change, and the exact library and
destination ownership marker. Obsidian metadata, the Notes folder and write
access must still be present. Missing folders, symlinks, changed folder IDs,
different owners and inconsistent devices remain blocked. No folders are adopted
or recreated as part of this recovery.

Preview remains read-only. A normal enabled sync batch refreshes the stored
identities only after all checks succeed, then resumes the existing export.
Your vault path and existing notes require no manual changes or reconfiguration.
No database schema migration is added. Includes the 1.19.1 startup hotfix.

Apple silicon and macOS 26+ remain required. Local installers use the existing
Apple Development signature, without Developer ID notarization.
