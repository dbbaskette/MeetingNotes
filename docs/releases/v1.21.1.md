# MeetingNotes 1.21.1 — one click to change group while renaming

## Fixed

On a meeting page, clicking the group button (**Add to group**, or the current
group's name) while the title was being edited saved the new title but did not
open the group dialog, so a second click was needed. The title field is wider
than the title, and the header moved back between pressing and releasing the
mouse, taking the button out from under the pointer.

One click now saves the title and opens the dialog. Ending an edit with Enter,
Esc, Tab or by switching windows is unchanged.

## Upgrading

Install 1.21.1 over 1.21.0 or 1.20.x. No database schema migration is added.
Apple silicon and macOS 26+ remain required. Local installers use the existing
Apple Development signature, without Developer ID notarization. GitHub
publishes source and release notes without binary attachments.
