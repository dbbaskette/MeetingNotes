# MeetingNotes 1.14.6

2026-10-07. Patch release for clearer recording-state feedback. GitHub release
is source-only; DMG/ZIP installers are built locally, not uploaded as assets.
The experimental remote-processing beta remains separate.

## Clearer Record controls

- **Record becomes “Recording active” and is disabled** while the UI knows a
  capture is active. The keyboard/menu shortcut provides neutral guidance
  without opening another source picker. A capture started elsewhere closes
  an already-open picker. Rapid duplicate source clicks send only one start.
- If another start still races with capture startup or shutdown, the UI asks
  the recorder for its state and displays clear **starting**, **already active**,
  **still stopping**, or **test recording** guidance. It no longer displays
  `Error invoking remote method 'recording:start'` for that expected condition.
- The current recording is never stopped or restarted by a rejected duplicate
  request. The backend's single-capture protection remains unchanged. If state
  cannot be confirmed, the UI does not guess or claim a new recording succeeded.
- Permission/startup failures remain actionable errors, with the transport
  wrapper removed. Detected-meeting and retry/restart controls share the same
  message handling; expected busy states are neutral, not alarming red failures.

## Verification and upgrade

- Full source unit suite: **1,209 passed, six skipped**. The 16 new feedback
  tests also passed after correcting their test-table typing.
- All eight existing isolated Electron renderer modes passed, including
  duplicate clicks, active-state/shortcut blocking, stale-picker closure,
  truthful Stop/retry, genuine error alerts and successful-start transitions.
  The final capture fixture and its feedback screenshot were checked again
  after allowing the screenshot to paint.
- Main/preload production build, renderer/fixture types and whitespace checks
  passed. Scoped lint had zero errors and three pre-existing hook warnings.
- Patch version/README metadata are updated to 1.14.6. Dependencies and database
  schema are unchanged; valid source-test evidence is reused for metadata-only
  release preparation. No real microphone/call or account/vault acceptance is
  claimed. Installer VM testing is intentionally omitted at the owner's request.

Requires macOS 14.2+ / Apple Silicon. Keep a complete closed-app Library backup
before replacing the installed app. This patch adds no migrations and does not
move recordings or reset permissions/settings. Building does not install the
app or interrupt an active recording.

Local installers use the existing Apple Development signing identity and are
**not notarized** because notarization is not configured. They are not a
notarized public-distribution build.
