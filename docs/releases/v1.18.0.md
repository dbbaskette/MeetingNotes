# MeetingNotes 1.18.0 — optional automatic voice matching

Native voiceprints can now name clearly matching speakers automatically, rather
than only offering suggestions. The setting is optional and off by default.
Apple transcription, SpeakerKit, recording and the Golden Gate interface remain
the same; no new model downloads or accounts are required.

## Turn it on

Open **Settings → Processing → Automatically match known voices**. The setting
applies on the next identification run; it does not rename existing meetings or
undo existing assignments when turned off. Confirm voices in native meetings
first to build profiles for your saved people. Historical Whisper-era embeddings
remain separate and are not silently converted or mixed with native profiles.

## Conservative matching safeguards

- Raw cosine similarity must be at least **0.98**, with a **0.05** lead over
  the next compatible profile. Decisions use unrounded scores.
- A voice must have at least **10 seconds of non-overlapping speech** across
  **two distinct merged turns**, each with at least 1.5 seconds of clean speech.
  Overlap, duplicate segments and adjacent fragments do not inflate evidence.
- Short or ambiguous voices stay in review. If two eligible voices claim the
  same person, neither wins by input order. Already-linked identities are reserved.
- Profiles must use the same model space and vector dimensions. Missing, zero
  or malformed vectors cannot become automatic matches; invalid timing fails closed.
- Automatic identification never trains a voiceprint from its own guess.

These are experimental opt-in heuristics, not calibrated accuracy guarantees.
A similarity of 0.99 does **not** mean a 99% probability of the correct identity.

## Clear labels and human control

Automatic names show **Auto-matched · similarity …**, even for a perfect score.
The speaker header includes an auto-matched count when named voices are folded.
Open a voice to listen, assign another person, unassign it, or choose
**Confirm this voice**. Explicit confirmation teaches the native profile through
the existing human assignment path and replaces the automatic label.

When every voice satisfies the review gate, processing continues using the
matched names in the transcript before notes are generated. Unknown voices keep
the existing review workflow. Existing links survive identification retries for
the same artifact; explicit new diarization still creates run-local labels.

## Upgrade and rollback

Finish active recording/processing, quit and make a Library backup before
replacing the app. Apple silicon and macOS 26+ remain required. Already-ready
speech assets do not need preparation again; summaries still use your configured
LLM. Upgrading does not reprocess meetings.

Schema migration 25 adds only a nullable automatic/manual assignment-source
field. Existing speaker links, names, scores and voiceprints are retained.
Old links are not relabeled as automatic. Keep the 1.17.0 installer as a rollback
option; reinstalling an older app does not reverse the migration, later edits,
profile confirmations or explicitly regenerated outputs. Restore a pre-upgrade
Library backup if data rollback is needed.

GitHub publishes source and these notes without binary assets. Local arm64
DMG/ZIP installers are built separately. The existing Apple Development signing
is not Developer ID notarization. Building does not install or restart the app.
