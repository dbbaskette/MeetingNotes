# MeetingNotes 1.10.1

**Release date:** 2026-08-13

This is a GitHub source release. It intentionally does **not** attach DMG or ZIP binaries. Build the Apple Silicon installer locally with `npm run dist`; the generated files appear under `release/`.

## Highlights

### Speaker review is readable again

The compact speaker rail is only 240px wide on desktop. In 1.10.0, confidence badges, the **Needs review** marker, bulk-selection checkbox, and disclosure control competed with the speaker identity text in one flex row. Long names and status text could collapse into one word or character per line.

1.10.1 moves review badges into a wrapping status row beneath the speaker identity and keeps the identity/details column shrink-safe. Existing speaker links, confidence values, review states, samples, and bulk assignment behavior are unchanged.

### Clearer review semantics

The `named` counter continues to report roster links. **Probably <name> <confidence>%** and **Needs review** remain separate signals: a linked speaker can still need confirmation when confidence is low or the diarization evidence is sparse.

## Upgrade notes

- Requires macOS 14.2+ on Apple Silicon.
- Existing meetings, recordings, roster entries, and speaker links remain in place.
- No database migration is required for this patch release.
- A local LLM runtime and the existing Whisper/pyannote setup remain unchanged.

## Build locally

```bash
git clone https://github.com/dbbaskette/MeetingNotes.git
cd MeetingNotes
git checkout v1.10.1
npm install
npm run dist
```

The installer artifacts are generated at `release/MeetingNotes-1.10.1-arm64.dmg` and `release/MeetingNotes-1.10.1-arm64-mac.zip`.
