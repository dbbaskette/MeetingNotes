# MeetingNotes 1.19.0 — clearer voices and meeting follow-through

This release implements twelve improvements spanning voice identity, processing,
search, organization and everyday follow-through. No new accounts or model downloads
are required. Apple Silicon and macOS 26+ remain the supported platform.

## Voices you can trust and maintain

1. **Voiceprints survive roster merges.** Compatible native profiles move to the
   surviving person, including profiles from different model spaces. Incompatible
   dimensions are rejected before writing. Original source files remain as recovery
   copies; target changes have undo history. Database merge failures roll back the
   profile writes. Startup duplicate cleanup also preserves native profiles.
2. **Understand matching decisions.** Open a voice to see whether it lacks enough
   clean speech, has weak similarity, conflicts with a close runner-up, duplicates
   another claim, or names someone already assigned. Automatic matching remains
   opt-in and never trains on its own guesses.
3. **A compact voiceprint manager.** Search the roster in Settings, show ten people
   at a time, and expand Voiceprints only when needed. New confirmations retain their
   meeting/voice source, date and up to twenty undo steps. Undo changes future voice
   matching, not existing meeting names. Earlier profiles remain readable; missing
   historical provenance is labeled rather than invented.
4. **Lighter speaker review.** Suggestions are fetched in one meeting-wide batch.
   Diarization reads reuse the artifact cache and saved profiles use a bounded cache
   invalidated by file identity or app writes. Audio clips remain lazy-loaded.

## Processing and search

5. **Search scans the selected meetings.** Group/date/speaker/status filters select
   eligible folders before content scanning. Bounded batches retain cancellation,
   timeouts and result limits; an empty selection never scans the whole Library.
6. **Visible work and targeted cancellation.** The status bar distinguishes
   transcription and voice analysis. Transcription reports audio coverage, while
   voice analysis honestly shows waiting/running/complete rather than a made-up
   percentage. Cancel current stops that meeting's work, preserves original audio,
   and leaves the rest of the queue available. Pause still means “finish current,
   then stop taking more.” A cancelled meeting offers the normal retry workflow.
7. **Memory-aware speech scheduling.** Recordings of an hour or more, unknown-length
   recordings, or a Mac with under 2 GiB free memory run transcription and voice
   analysis sequentially. Shorter recordings with sufficient free memory retain
   parallel execution. The whole-recording diarization identity model is unchanged;
   this reduces overlapping working sets, not SpeakerKit's own full-audio buffer.
   Audio decoding also reserves the final sample array and avoids intermediate
   float-array copies. On the existing synthetic 75-minute fixture, peak summed
   helper RSS fell roughly 18–19%; this excludes Apple service/GPU memory and is
   not a guarantee for real meetings. PCM parity tests cover mono/stereo and
   16/44.1/48 kHz input without changing resampling boundaries.
8. **Readable filters and keyboard navigation.** Chips show names and friendly
   status labels. Keyboard selection scrolls search results into view, announces
   the active result, and the bottom processing status opens with Enter or Space.

## Organization and follow-through

9. **Pinned groups.** Choose Pin group in its menu. Ungrouped remains at the top,
   followed by pinned groups, then other groups alphabetically. Pins persist locally.
10. **Live Actions.** A top-level Actions view lists current unfinished tasks across
    all meeting dates—not just this week's meetings. Filter My actions/Everyone/a
    named owner, group, overdue, next seven days or undated. Mark done or open the
    source meeting; editing is disabled while that meeting is processing. Set your
    identity in Settings to use My actions. Results page in sets of 100.
11. **Prepare next meeting.** A group's menu opens saved decisions, open questions
    and overviews from its five latest completed meetings, plus current open tasks
    from the whole group. Every section links to its source. It uses existing notes,
    does not generate new claims, and explicitly labels unavailable notes and limits.
12. **Notes first, names later.** Enable the optional Processing setting to continue
    past unnamed voices. The summary prompt preserves exact diarizer labels for later
    resolution. Naming voices updates the transcript and exact labels in existing
    notes/action items, preserving edits and a Notes history snapshot. Human names
    are never globally substituted, and saved weekly reports are not rewritten.

## Upgrade and recovery

Install over the previous version using your existing Library and prepared speech
assets. The additive database migration adds group pins and an action-status index.
No meetings or original audio are removed. Voiceprint history lives in the existing
Library voice-profile folder; old source profiles retained after merge are intentional.

Use the Library backup feature before a downgrade. Older versions do not expose the
new settings/pins and may discard undo metadata if they train a profile. Undoing a
voiceprint is not an undo of the roster merge itself. Notes history can restore notes
and tasks before speaker-label resolution. Installer builds are local; this GitHub
release publishes source and notes without binary assets. Apple Development signing
is not Developer ID distribution/notarization.

## Verification

Regression coverage includes merge/profile recovery and cache invalidation, filtered
search, scoped cancellation, sequential scheduling, notes-first continuation,
group ordering and cross-meeting tasks. Populated synthetic UI checks exercise
Actions and group preparation alongside the existing light/dark/narrow-window suite.
See [the verification record](../reviews/2026-10-22-usability-performance.md) for
measured results, tested revision and limitations.
