# MeetingNotes 1.13.0

**Release date:** 2026-10-02

Keep your meeting knowledge in Obsidian without maintaining duplicate notes. Version 1.13.0 adds optional, local, one-way vault sync with group and date views, safe update handling, and a compact Settings flow. This GitHub release is source-only; installers are built locally, not uploaded as release assets.

## What's new

- **Choose your vault once:** Settings → Obsidian sync → Configure… accepts an existing vault root. Preview shows the destination and completed-meeting count before **Enable and sync** starts the backfill. Sync defaults off.
- **One note, several views:** a dedicated folder contains one stable Markdown file per meeting, an Obsidian Base with **By group**, **By date**, and **Ungrouped** views, a customizable landing page, and a plugin-free link index. Group moves and title changes update metadata without duplicating files. Dates use the actual meeting start, with creation time as a fallback.
- **Choose your content:** action items default on; full transcripts default off; audio is never copied. Tasks are explicitly labeled as one-way copies.
- **Stay current:** completed processing, edited notes, terminology corrections, speaker names, action items, and group changes feed a durable revision queue. Restart catch-up and 100-meeting batches keep the integration independent of processing success. Unchanged exports are not rewritten.
- **Keep personal annotations:** MeetingNotes updates only its generated section and owned meeting properties. Personal notes and additional YAML properties survive updates. Edits to generated content pause that note instead of silently overwriting it.
- **Review conflicts:** compare current and proposed versions, save a separate latest copy, or explicitly replace generated content after a backup. Stale comparisons and changed ownership block replacement.
- **Safe recovery:** interrupted writes have a durable journal; renamed notes can be reconciled; missing notes, replaced/unavailable vaults, symlinks, and conflicting folders are reported. Removed source meetings retain their exports but leave active views. Custom landing/Base views are preserved; explicit view repair backs them up.
- **Compact controls:** Settings shows a status card. Configuration and a bounded issue list live in a scrollable dialog, with retry, open-folder, disable, and repair controls.

## Getting started and privacy

See the [Obsidian sync guide](../obsidian-sync.md). Enable Obsidian's built-in Bases plugin for the interactive views; `Browse.md` works without it. The integration does not install plugins or change vault configuration.

Sync runs while MeetingNotes is open and is not bidirectional. A vault configured with Obsidian Sync, iCloud, Dropbox, Git, or another service may distribute exported meeting content outside this Mac. Choose the vault and content options accordingly. The local database journal also contains exported text; protect library backups.

## Upgrade and rollback

- Requires macOS 14.2+ on Apple Silicon.
- **Migration 19 is additive:** it adds sync ownership, source revisions, per-destination manifests, and write journals. Existing audio, summaries, dictionary data, and group assignments are not relocated or replaced.
- Back up the complete library, including `db.sqlite` with MeetingNotes closed, and your vault before upgrading.
- Disable sync to stop writes; existing exports remain. Changing destinations also leaves the old folder intact.
- For a full rollback to 1.12.8, quit the app and restore the pre-upgrade library backup with the older app. Keep the current library/vault copies for recovery. Downgrading the binary alone does not undo migration 19 or exported files.

## Verification and known limits

- Full test suite: **981 passed, 6 skipped** across 125 passing and 2 skipped files, including 23 new sync tests. Production build, main/preload/renderer type checks, changed-file lint, and whitespace checks passed.
- A disposable 500-meeting fixture exported in about **3.2 seconds**; an unchanged pass took **0.7 ms** with no writes. These local synthetic timings are not performance guarantees.
- The isolated Electron UI fixture passed first-sync confirmation, reconfiguration, 100 issue rows, conflict and repair confirmations, disable, focus restoration, and narrow-window layout.
- Bases syntax/YAML was checked against official documentation and automated fixtures. **Live Obsidian rendering remains a manual compatibility check:** Obsidian 1.13.7 was available, but the UI selector could not safely target its temporary instance independently of the user's existing window. No user vault was modified. Group collapse behavior is not claimed to match MeetingNotes; Bases uses alphabetical groups, while the fallback index puts Ungrouped first.
- Notes are limited to 12 MB; rename reconciliation is limited to 5,000 files in the owned Notes folder. Concurrent external edits are checked before writes, but the integration is not a cross-application lock. Keep vault backups/version history and avoid editing generated sections during sync.
- The dependency audit still reports a pre-existing production advisory in `undici`; this release does not change that dependency. The added YAML dependency had no reported advisory at verification time.

## Local installers

Build from `v1.13.0` with `npm run dist`. Outputs:

- `release/MeetingNotes-1.13.0-arm64.dmg`
- `release/MeetingNotes-1.13.0-arm64-mac.zip`

The local build uses an Apple Development certificate. Apple notarization is not configured. Building these packages does not replace or restart the installed app.
