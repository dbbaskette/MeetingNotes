# MeetingNotes 1.19.1 — startup hotfix

Fixes a startup exception in 1.19.0: `ActionFilterSchema` was missing when the
main process loaded the Actions repository. The preload compiler had overwritten
the shared ESM module with CommonJS output. Main and preload builds now use
separate output trees, and both stable and beta windows load their isolated preload.

Every production build now imports the emitted shared modules and Actions
repository to catch module-format/export failures. Local CI also launches the real
built app against a disposable synthetic library after building.

Install 1.19.1 over 1.19.0. This hotfix changes packaging and startup only; it
adds no database migrations and retains the twelve improvements in 1.19.0.
Apple silicon and macOS 26+ remain required. Installers use the existing Apple
Development signature; they are not Developer ID notarized. GitHub publishes
source and release notes without binary attachments.

Verification: 1,393 regression tests passed. The actual packaged app opened its
populated synthetic Library with normal and software rendering and passed real
Actions/speaker-review IPC checks. Clean-Mac build/startup checks also passed.
See the [verification record](https://github.com/dbbaskette/MeetingNotes/blob/v1.19.1/docs/reviews/2026-10-22-startup-hotfix.md).
