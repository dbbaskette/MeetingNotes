# MeetingNotes 1.12.2

**Release date:** 2026-09-22

This is a source-only GitHub release. The Apple Silicon DMG and ZIP are built locally and are not attached to GitHub. The experimental remote-processing beta remains separate; recording and processing in 1.12.2 stay on the Mac.

## Highlights

### Export notes to PDF

The meeting Export panel now offers PDF alongside Markdown. Select all, some, or no action items; selecting none produces notes only. PDF rendering runs locally in an isolated Electron window and writes to the location chosen in the Save dialog. The export does not upload meeting content.

### One accurate action-item list

Generated summaries can already contain an Action Items section. PDF, Markdown, and Google Doc exports now remove that generated section before adding the selected action items from the meeting database. This avoids duplicate or stale tasks. A notes-only Markdown export omits the Action Items heading entirely. Google Doc export still sends the selected content to Google when explicitly chosen.

### Clearer export feedback

- Open and completed action items are grouped in the picker; completed items start unselected. Personal task destinations show only open items assigned to you.
- Notes-only PDF and Markdown saves confirm the destination path.
- A failed Google connection check shows its error and a Retry control instead of silently disabling the buttons.
- The export picker cancels its delayed close when unmounted, so an old timer cannot close a newly opened picker.

### Faster navigation and less status polling

Detail, Weekly, Settings, and Onboarding views load when opened rather than in the initial renderer bundle. The main production JavaScript chunk went from approximately 524 kB to 240 kB uncompressed; first-navigation latency has not been benchmarked. Meeting detail refreshes on persisted pipeline stage/status events, with a 15-second fallback poll for missed events instead of a two-second loop. The Weekly narrative timer now updates once per second.

### Smaller code boundaries

Transcript, action-item, speaker, and export panels are separate modules. Export, Weekly, and Settings/Onboarding IPC handlers have separate registration modules while retaining the existing shared entry point. Weekly IPC payload types and exporter selection metadata are shared across main and renderer, reducing contract drift.

## Upgrade and rollback

- Requires macOS 14.2+ on Apple Silicon.
- No database migration is required. Existing recordings, meetings, settings, speakers, and action items remain in place.
- Back up the meeting library before upgrading. Keep the prior installer if you may roll back; do not delete the library or source recordings.
- Local Whisper, pyannote, and LLM setup is unchanged. Google and webhook exports remain optional network integrations.

- The full serial Vitest suite passed: 117 test files passed, 2 opt-in files skipped; 914 tests passed, 5 skipped.
- Sidecar tests passed: 9 tests. `npm audit --omit=dev --audit-level=high` reported 0 vulnerabilities.
- Targeted ESLint checks passed for changed source files; repository-wide lint still has previously recorded unrelated errors.

## Build locally

```bash
git clone https://github.com/dbbaskette/MeetingNotes.git
cd MeetingNotes
git checkout v1.12.2
npm install
npm run dist
```

The expected outputs are `release/MeetingNotes-1.12.2-arm64.dmg` and `release/MeetingNotes-1.12.2-arm64-mac.zip`. Their identity, checksums, and signature should be verified after the local build; no binary checksum is claimed by this source release.

## Known limitations

- The local app uses an Apple Development certificate. Apple notarization is not configured, so the installer is not claimed as notarized.
- The production renderer still lacks a Content Security Policy. Runtime/toolchain upgrades and CSP hardening need separate compatibility verification.
- Production-only dependency audit does not cover Electron or every bundled build tool.
- No Cloud Foundry service or remote-processing capability is included in this stable release.
