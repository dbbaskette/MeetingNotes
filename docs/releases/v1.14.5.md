# MeetingNotes 1.14.5

2026-10-07. Cumulative update since 1.13.2: completed epics #242/#243,
reviewed contributor changes, and a high-contrast icon. The experimental
remote-processing beta is not included. GitHub release is source-only;
DMG/ZIP installers are built locally, not uploaded as release assets.

## A clearer application identity

- Bright pale rounded-square tile and bold indigo conversation/waveform mark
  replace the dark metallic notebook/pen. Dock, Finder and Library/Weekly share
  the artwork, checked at 16, 32 and 64 pixels on dark/light backgrounds.
- Explicit 16–1024px macOS representations and a lightweight 256px renderer logo.
  `npm run build:icons` reproduces the exports. App/lockfile version is 1.14.5.
- Install the new build to update the installed version/icon. Signing identity,
  permissions, settings and recordings are unchanged; the build does not reset
  the icon cache or replace the installed app.

## Reliable capture and guided processing

- Mic-only, app-only and mixed captures share a bounded aligned timeline with
  coordinated stems, gaps/resumption and finalization. All entry points share
  one start reservation; pending URL requests are validated and cancellable.
- Truthful Stop/retry controls and explicit All system audio restart retain group
  and title intent. App-grouped sources/Refresh preserve choices without auto-start.
- Optional titles persist before capture, survive recovery/restart and cannot
  be overwritten by generated-title races. Rename after Stop remains optional.
- Compact Setup & health, shared Whisper model choice/download progress,
  interrupted-download protection and explicitly confirmed disposable test.
- Prioritized processing diagnosis, bounded technical history, inline unresolved
  speakers and complete paged Needs attention. Reprocessing preserves notes/
  action history and local transcript snapshots.
- Opt-in processing after Stop defaults off: only new usable finalized built-in
  recordings qualify, never imports, recovery, historical discovery or tests.

## Organize, navigate and search

- Inline expandable groups stay Ungrouped-first. New arrivals have explicit
  acknowledgment; inline Move confirms fixed IDs with three recent successful
  destinations. Failures retain selection for retry. Nonzero full-group badges
  reveal unprocessed, in-progress/review and failed meetings.
- Keyboard row/checkbox actions, visible selection and retained Library/Weekly
  queries, groups, loaded pages and scroll after returning from a meeting.
  Hidden views do not own navigation keys. Query persistence requires explicit Save.
- Shared dialogs trap Tab, preserve unsaved text/focus, restore the trigger and
  honor topmost nested/busy Escape and backdrop ownership.
- Group Undo restores only unchanged assignments, refuses newer/ABA moves and
  respects native editor Undo. Every toast owns its original operation.
- Client-owned search cancellation stops actual subprocess work, isolates Library
  and Cmd+K, fences stale responses and distinguishes complete/partial/limited/
  cancelled/failed results. Incomplete searches do not imply an empty Library.
- Shared date/week, speaker, status, task ownership, source, recovery-warning and
  notes/transcript facets apply before caps. Removable chips and local named filters
  support explicit Save/rename/delete without hidden query storage.
- Variable-height long-transcript windowing with readable width, whole-text
  Find/copy/export, distant seek/focus and correction invalidation. Playback
  respects manual scrolling in both line and grouped modes.

## Trust Weekly tasks and recover safely

- Local Monday–Sunday weeks consistently handle timezone/DST/year boundaries.
  New instants use UTC; legacy timestamps are interpreted without rewriting rows.
- Narrative freshness hashes actual summary text, tasks and roster names.
  Concurrent normal/forced generation shares ownership; edits reject stale output.
- Complete/edit owner or due date/Snooze 1 week directly in Weekly; Mine, Overdue
  and Due this week filters preserve provenance and You grouping. Failures roll
  back with Retry; successful edits refresh counts and narrative freshness.
- Immediate individual-task Undo restores exact identity/metadata without
  overwriting newer user intent.
- Private local Library backup previews size/missing files, snapshots the actual
  active/canonical databases, includes recordings/external stems and excludes model
  caches. Idle/write coordination includes automatic vault sync.
- Locked inventory rechecks reject stale previews; checksums, complete audio
  mappings and SQLite integrity validate success. Restore only into a NEW
  destination. Incomplete copies remain marked and originals stay untouched.

## Delivery and contributor fixes

- Webhook ownership privacy/summary-only delivery, actual meeting IDs and
  retry-stable delivery UUIDs support deduplication. Delivery is at least once,
  not exactly once across restarts. Slack/Telegram text is escaped/bounded,
  redirects rejected and failures redacted. Google Tasks searches all task-list
  pages and coalesces creation.
- Contributor updates: app-grouped audible sources, unreadable-stub recovery,
  active-provider/managed LM Studio settings, configured Whisper host/port/provider,
  local diagnostic dates, Reminders dates/Google token preservation, startup
  recovery, unresolved-only speaker gating, launcher clean exits and reliable Finder.
- Packaging retains graphics/software fallbacks, licenses and notices.

## Verification, upgrade and limitations

The epic gate passed 1,193 tests (six skipped), native synthetic audio checks,
types/build/scoped lint, benchmarks and all eight renderer fixtures. Final
renderer-only checks also passed; unchanged backend/native evidence is reused.
Icon/version checks and production build pass. Dependencies are unchanged;
previous audit findings remain—not a clean security-audit claim.

Synthetic 12,000-line transcript: 12,000 → 17 mounted rows; initial React median
approximately 143 → 10 ms; playback median approximately 15 → 4.5 ms. These are
fixture results, not production guarantees or isolated memory-saving claims.
Installer VM testing is intentionally omitted at the owner's request. Prior
1.14.0 packaged-runtime checks do not establish 1.14.5 installer acceptance.
No real microphone/call, signed-in export or paid inference acceptance is claimed.

Requires macOS 14.2+ / Apple Silicon. Migrations 21–22 add processing history,
title intent and revision guards; recordings are not relocated and historical
timestamps are not rewritten. Keep a complete closed-app pre-upgrade Library
copy. App-only downgrade does not undo schema changes/exports; restore the
matching backup for schema rollback. Backups may contain private data/secrets.
