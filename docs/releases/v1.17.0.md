# MeetingNotes 1.17.0 — a clearer Golden Gate-inspired interface

The approved design now extends across the regular app, not only the Library.
This is a visual refresh of the existing Electron/React interface, with no
changes to recording, speech processing, saved meetings or the database.

## A calmer visual hierarchy

- Cool slate canvas and opaque reading surfaces replace the washed-out white
  presentation. Light and dark palettes are independently tuned.
- Integrated headers, navigation, search and compact menus use restrained
  material, subtle edges and highlights. Notes, transcripts and scrolling
  meeting rows stay free of backdrop blur.
- Expanded groups have a clear shared highlight; flatter meeting rows preserve
  checkbox selection, status edges, Move, menus and inline group organization.
- Meeting details have integrated title, tabs, speaker inspector and playback
  surfaces. Summary, transcript and action-item workflows remain the same.
- Weekly reports, all Settings sections, setup, permissions, quick search,
  source selection, dictionary, Obsidian and history dialogs share the palette.
- Filled accent commands keep readable white labels in both themes; navigation
  selection uses neutral raised controls. Text/selection token contrast is
  regression-tested. Keyboard focus, reduced-motion and opaque high-contrast /
  reduced-transparency fallbacks are retained.

## Reusable design skill

The MIT-licensed [Golden Gate design skill](../../macos-goldengate-skill/SKILL.md)
adapts GitHub's native-oriented skill into stack-neutral guidance for web,
React/Electron, SwiftUI/AppKit and other frameworks. It preserves the product's
existing structure and distinguishes CSS-inspired material from real OS glass.
Upstream attribution and source revision are included in the package.

## Upgrade

Finish capture/processing and quit before replacing the app. Existing meetings,
groups, saved reports, voice profiles, corrections and settings stay in place.
There is no migration or automatic reprocessing. Already-ready Apple/SpeakerKit
assets do not need preparation again. New installations still require Apple
silicon/macOS 26+, explicit native speech preparation, a summary LLM and FFmpeg.

GitHub publishes source and these notes without binary assets. Local arm64
DMG/ZIP installers are built separately, with Apple Development signing rather
than Developer ID notarization. Building never replaces or restarts the running
app. Keep the 1.16 installer as the visual rollback; rollback does not undo
explicit processing or edits performed afterwards.

## Verification and limits

The isolated appearance fixture exercises five real screens in light/dark and
desktop/narrow layouts, detail tabs, navigation, disclosure, dialog focus,
source selection and reduced-effects fallback. Existing fixtures retain scroll,
selection, naming, processing and persistence coverage. All fixtures use
synthetic data, with no recording, real integrations or model preparation.
See the [verification report](../reviews/2026-10-16-golden-gate-release.md) for
the tested source, full-suite results and local artifact identity.

Material is a CSS approximation, not native system Liquid Glass, and does not
claim OS tint/inactive-window integration. Preference availability depends on
Chromium; opaque baseline surfaces remain readable without blur. No installer
VM acceptance or new real-microphone/speech-quality evaluation is claimed.
