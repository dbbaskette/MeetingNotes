# MeetingNotes 1.21.0 — motion in the interface

This release adds four interaction patterns adapted from Cult UI. They are
written for MeetingNotes rather than installed from that library, and animation
is limited to navigation, controls and transient surfaces: meeting rows, notes
and transcripts stay still.

## Recording pill

While a recording is running and you are on Actions, Weekly, Settings or a
meeting, a small pill in the title bar shows the elapsed time and a level meter.
Click it to drop down the full recording controls, including **Stop** and
**Restart with All system audio**. Press Esc or click elsewhere to close it. It
replaces the full-width recording banner on those screens; the Library keeps its
inline recording row.

## Needs attention can be collapsed

Click the **Needs attention** heading to fold the inbox to one line that counts
each group, for example "1 processing failed · 1 speaker review · 2 ready to
process". The choice is remembered on this Mac. A failed refresh or action
reopens it so an error is never hidden.

The capture-recovery **Delete…** and **Preview / trim** panels now open and
close smoothly instead of jumping the list.

## Tabs and selection

- The selected highlight glides between **Library / Actions / Weekly /
  Settings**, between **Organized / All meetings**, and between Settings
  sections.
- A meeting's **Summary / Transcript / Actions** are now a proper tab list. With
  a tab focused, Left and Right move between tabs, and Home and End jump to the
  first and last. Screen readers announce them as tabs.

## Toasts

- Toasts slide in and out, and the rest close the gap smoothly.
- The countdown pauses while the pointer or keyboard focus is on a toast.
- **Error toasts now stay until you dismiss them**, unless the action sets its
  own time. They are announced immediately by screen readers.
- At most four toasts are shown at once.

## Behaviour changes to know about

- With a meeting tab focused, Left and Right change tabs instead of skipping
  audio by 15 seconds. They still skip audio everywhere else on the page.
- Error toasts no longer disappear after six seconds.

## Accessibility and performance

Animations follow **System Settings → Accessibility → Display → Reduce Motion**.
The animation engine loads after the first screen is drawn; the code needed at
launch grew by about 18 kB compressed.

## Upgrading

Install 1.21.0 over 1.20.x. No database schema migration is added. Apple silicon
and macOS 26+ remain required. Local installers use the existing Apple
Development signature, without Developer ID notarization. GitHub publishes
source and release notes without binary attachments.
