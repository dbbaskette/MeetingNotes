# MeetingNotes 1.11.0

**Release date:** 2026-08-31

This is a GitHub source release. It intentionally does **not** attach DMG or ZIP binaries. Build the Apple Silicon installer locally with `npm run dist`; the generated files appear under `release/`.

## Highlights

### Navigation that behaves like a Mac app

Library, Weekly, and Settings now share one persistent navigation shell, so Settings is reachable from every top-level view. MeetingNotes also keeps a real navigation history: use **Command-[** and **Command-]** or the View menu to move backward and forward without losing your place.

Unsaved summary edits remain protected. Every navigation path—including menu actions, search results, deep links, and history traversal—passes through the same discard confirmation.

### Recording failures are no longer silent

If the recording helper exits unexpectedly, MeetingNotes now shows an error toast with the failure reason and confirms that audio captured so far was saved. **Record again** retries with the same application and microphone settings instead of making you reconstruct the source selection.

Normal manual stops and the five-minute no-audio auto-stop continue to save and finalize recordings without showing a failure warning.

### Consistent confirmations and icons

Bulk deletion, speaker merging, and unsaved-summary discard now use themed in-app confirmation dialogs rather than macOS browser-style prompts. The dialogs support Escape, safe initial focus, and keyboard focus containment.

UI emoji have been replaced with a consistent current-color SVG icon set, producing predictable weight and contrast in light and dark themes.

### Export requirements are visible

Disabled export actions now explain their requirements directly beneath the button—for example, signing in to Google, identifying yourself, or generating a summary—rather than hiding the reason in a hover-only tooltip.

### Release hardening

- Updated the production HTTP client to `undici` 6.28.0, resolving the high-severity advisories reported against the prior dependency version.
- Fixed frozen diarization sidecars so their health response reports the same stamped build ID that the Electron supervisor reads from the installed app.
- Corrected the post-test Electron native-module rebuild command so it completes instead of silently ignoring an unsupported option.

## Upgrade notes

- Requires macOS 14.2+ on Apple Silicon.
- Existing meetings, recordings, settings, action items, and speaker links remain in place.
- No database migration is required.
- A local LLM runtime and the existing Whisper/pyannote setup remain unchanged.

## Build locally

```bash
git clone https://github.com/dbbaskette/MeetingNotes.git
cd MeetingNotes
git checkout v1.11.0
npm install
npm run dist
```

The installer artifacts are generated at `release/MeetingNotes-1.11.0-arm64.dmg` and `release/MeetingNotes-1.11.0-arm64-mac.zip`.
