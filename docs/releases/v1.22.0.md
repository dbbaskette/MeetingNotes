# MeetingNotes 1.22.0 — ask your meetings

## Ask a question across all meetings

Open search with ⌘K, type a question such as "What did we decide about
pricing?" and press **Shift+Enter**, or click **Ask**. The local model answers
from the notes and transcripts of every meeting and cites numbered sources.
Click a source to open that meeting; transcript sources open at the quoted
moment.

- Answers come only from passages found in your library. When nothing relevant
  is found the app says so and does not guess.
- Everything stays on this Mac. Questions and answers are not written to logs.
- The first question builds a search index inside the library database. On a
  library of about 300 meetings this takes around a second and adds roughly
  17 MB. It updates itself when notes or transcripts change.
- Matching is by words, so a question phrased very differently from what was
  said can miss. Answer quality depends on the local model you have chosen.

## Voice naming

Measured on 61 meetings with 204 hand-named voices, the previous matching bar
named about 1% of returning voices. This release changes three things:

- **Automatic matching names far more voices.** The similarity bar moves from
  0.98 to 0.80. In the same measurement that named 74% of returning voices with
  no wrong names. The lead over the next candidate and the ten seconds of clear
  speech are still required, and the setting is still off by default.
- **One-click suggestion.** An unnamed voice with a clear best guess shows
  "Sounds like … · Confirm" on its row. It is not offered when that person is
  already named in the meeting.
- **Brief voices do not hold a meeting.** An unnamed voice with under ten
  seconds of speech no longer pauses processing for review. Such voices are
  listed under a collapsed "brief voices" row and can still be named.

## Fixed

- **Drag-and-drop import** did nothing, with no message. It works again, copies
  into the library's own recordings folder, and tells you when a drop contains
  nothing it can import.
- **A meeting that no longer exists** showed a loading page forever. It now says
  the meeting is unavailable.
- **⌘R and File ▸ Record** did nothing outside the Library. They now go to the
  Library and open the source picker.
- **The Library refreshed itself about a hundred times per transcribed meeting.**
  It now refreshes only when the processing queue changes.

## Behaviour changes to know about

- A meeting whose only unnamed voices are brief now runs straight through to
  the summary. The Library's unnamed-voice count still includes them.
- Drag-and-drop accepts `.m4a` and `.mp3` only. `.wav`, `.aac` and `.flac` were
  advertised before but never appeared in the Library after a drop.
- With automatic matching on, more names are applied without review. They are
  labelled as automatic and stay editable; only your confirmations train a
  voiceprint.

## Upgrading

Install 1.22.0 over 1.21.x. No database schema migration is added; the search
index is created the first time you ask a question. Apple silicon and macOS 26+
remain required. Local installers use the existing Apple Development signature,
without Developer ID notarization. GitHub publishes source and release notes
without binary attachments.
