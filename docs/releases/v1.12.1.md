# MeetingNotes 1.12.1

**Release date:** 2026-09-14

This GitHub source release records the 1.12.1 follow-up to the Library and artifact-loading work in 1.12.0. Binary assets are intentionally not attached to GitHub. Build the Apple Silicon installer locally with `npm run dist` (or `./scripts/rebuild.sh`); the generated files appear under `release/`.

The experimental 1.13.0-beta.1 remote-processing branch remains separate and is **not included** in this release. Recording and processing stay local.

## Highlights

### A faster speaker-ID gate

Speaker-review overlap matching is now a sorted two-pointer pass instead of a nested full scan, and per-speaker line and duration counts are computed in one sweep. Bulk assign routes through the async artifact cache rather than a second synchronous parse.

On the UI, voices that still need review are listed above already-named voices in the right rail, so the unblock step reads as a short checklist.

### Search and attention fail open

⌘K search failures no longer look like “No matches.” The palette shows the error and a Retry control, matching Library search.

Needs Attention keeps the previous inbox when recovery or attention hydration fails, surfaces Retry, and caps each group at eight rows with a “+N more” note. Attention hydration uses a lightweight shell payload so status lists skip speaker and action-item joins.

### Cheaper continuation refreshes and transcript opens

Continuation pages of the same Library query reuse the first-page `counts()` snapshot instead of rescanning the live table once per loaded page. Opening the Transcript tab skips `transcript.raw.json` when markdown already exists. `J` / `K` move the highlight through the virtualized library list.

## Upgrade notes

- Requires macOS 14.2+ on Apple Silicon.
- Existing meetings, recordings, settings, action items, and speaker links remain in place.
- No database migration is required.
- A local LLM runtime and the existing Whisper/pyannote setup remain unchanged.
- Back up the meeting library before upgrading. Keep the prior installer if you may roll back.

## Build locally

```bash
git clone https://github.com/dbbaskette/MeetingNotes.git
cd MeetingNotes
git checkout v1.12.1
npm install
npm run dist
```

The installer artifacts are generated at `release/MeetingNotes-1.12.1-arm64.dmg` and `release/MeetingNotes-1.12.1-arm64-mac.zip`.

## Known limitations and security status

- The production-only audit result does not include Electron or all build tools, even though Electron is shipped in the app. This source publication does not claim a vulnerability-free packaged runtime or production security qualification.
- The production renderer still lacks a Content Security Policy. Runtime/toolchain upgrades and CSP hardening need separate compatibility verification.
- Library counts, global Needs Attention coverage, loaded-prefix refreshes and exact cross-page selection are not constant-time operations.
- No Cloud Foundry service or remote-processing capability is introduced by this stable release.
