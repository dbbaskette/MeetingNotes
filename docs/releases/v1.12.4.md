# MeetingNotes 1.12.4

**Release date:** 2026-09-25

This stable update makes the groups introduced in 1.12.3 part of the Library list itself. The GitHub release is source-only; the Apple Silicon DMG and ZIP are built locally and are not attached to GitHub. The separate remote-processing beta is not included.

## Highlights

### See groups and meetings together

- The Library defaults to **Organized**: named groups appear alphabetically as expandable sections, followed by **Ungrouped**. Each meeting appears only inside its assigned section, not again in a separate all-meetings section.
- Expand or collapse groups independently. The choice persists on this Mac; Ungrouped starts expanded on first use. Empty groups remain visible so they can be populated later.
- **View** on a group focuses the existing paged group list; **All groups** returns to the organized list. **All meetings** restores the flat, sortable library when a cross-group scan is more useful.
- Create groups from **+ New group**, and rename or delete named groups from their section menus. The existing row, detail, and bulk **Move to group…** actions remain available. Deleting a group unassigns its meetings without deleting audio or notes.

### Keep large libraries usable

- Collapsed sections do not fetch meeting rows. Each expanded section loads a bounded first page and has its own **Load more** control. Focused-group and flat views retain the existing virtualized list.
- Status filters work across sections. Inline search groups matches under their assigned group, shows each result once, and temporarily opens matching sections; clearing search restores the saved expansion state. Quick search (⌘K), Needs Attention, and Weekly remain cross-group.
- **Select all loaded** uses the meetings loaded in expanded sections; **Select all matching** resolves the full filtered set, including collapsed sections. Existing fixed-snapshot bulk-selection semantics are unchanged.

## Upgrade and rollback

- Requires macOS 14.2+ on Apple Silicon. Back up the meeting library before upgrading and keep the 1.12.3 installer if you may roll back.
- No new database migration, audio-file move, capture change, processing change, or remote service is introduced. The group metadata created by 1.12.3 remains compatible. This release replaces the previous group-selector presentation with inline sections.
- Expansion and Organized/All meetings choices are local UI preferences. Existing meetings stay assigned to the same single group (or Ungrouped). Rolling back to 1.12.3 restores its selector-style Library without changing those assignments.

## Verification

- Production TypeScript/Vite build passed. Full Vitest suite: 120 files and 930 tests passed; 2 opt-in files and 6 tests skipped.
- Sidecar tests: 9 passed. The Python processing bundle is unchanged by this UI update.
- The opt-in 1,000/10,000-meeting pagination benchmark passed. On the 10,000-meeting synthetic fixture, a group-scoped page query measured 0.118 ms median and the scoped count query 0.523 ms median on the local machine. These are query measurements, not end-to-end UI latency promises.
- New section-ordering, exactly-once search grouping, and expansion-preference tests passed. New source files passed targeted ESLint; repository-wide lint still contains pre-existing errors.
- `npm run dist` built the Apple Silicon DMG and ZIP. The ZIP passed its archive integrity test; a read-only mounted DMG reports app version 1.12.4, contains the audio-tap helper and Python sidecar, and passes strict deep macOS code-signature verification with normal keychain access. SHA-256 checksums for this local build are reported with the release handoff.
- A live recording and full visual smoke test against the user's meeting library were not performed; no active capture or processing workflow was interrupted.

## Build locally

```bash
git clone https://github.com/dbbaskette/MeetingNotes.git
cd MeetingNotes
git checkout v1.12.4
npm install
npm run dist
```

Expected outputs: `release/MeetingNotes-1.12.4-arm64.dmg` and `release/MeetingNotes-1.12.4-arm64-mac.zip`. Verify the local artifact's version, signature, and checksum before distributing it. GitHub does not carry these binaries.

## Known limitations

- The local app uses an Apple Development certificate. Apple notarization is not configured, so the installer is not claimed as notarized.
- A meeting can belong to only one group. Groups do not yet have nesting, manual pinning/reordering, or drag-and-drop assignment.
- Expanding a group loads its first page; deeper meetings require **Load more**. The production renderer still lacks a Content Security Policy.
