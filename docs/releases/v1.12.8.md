# MeetingNotes 1.12.8

**Release date:** 2026-09-30

Dictionary management now has its own space. Settings stays compact whether you have a handful of corrections or hundreds. This GitHub release is source-only; Apple Silicon installers are built locally and are not attached to GitHub.

## What's improved

- **Compact Settings:** Dictionary shows the number of saved corrections, a **Manage dictionary…** button, and the existing learning-offers toggle. The full rule list no longer occupies the Settings page.
- **Dedicated manager:** A bounded dialog contains the scrollable correction list. Search, group filtering, and Add correction remain above the list, so long dictionaries do not push those controls out of reach.
- **Search and scope:** Search both original and replacement text, ignoring case and surrounding spaces. Show all scopes, only library-wide rules, or a specific group. Empty results explain how to broaden the search.
- **Focused editing:** Add, Edit, Enable/Disable, and Delete stay in the manager. Adding while filtering a group defaults the new rule to that group. Search and group choices survive edits.
- **Safer keyboard navigation:** The native modal keeps focus inside the manager and restores it to Manage dictionary when closed. Escape supports closing/backing out, unfinished edits require confirmation before discarding, and deletion confirmation stays inside the dialog.

## What stays the same

Correction storage, group/library rule behavior, Suggest defaults, opt-in Automatic replacement, history, Undo, recording, and processing are unchanged. The existing learning-offers toggle is still directly accessible in Settings.

## Upgrade and rollback

- Requires macOS 14.2+ on Apple Silicon.
- No database migration or audio/file relocation is introduced in 1.12.8. Upgrading from 1.12.7 retains the existing dictionary and correction history.
- Back up the library before upgrading. Users upgrading from 1.12.6 or earlier also receive the terminology migration introduced in [1.12.7](v1.12.7.md); review that release's backup and rollback guidance.
- Returning to 1.12.7 restores the inline Settings editor without reversing saved rules. Older code does not reverse migrations or artifact corrections.
