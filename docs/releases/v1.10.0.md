# MeetingNotes 1.10.0

**Release date:** 2026-08-13

This is a GitHub source release. It intentionally does **not** attach DMG or ZIP binaries. Build the installer locally on Apple Silicon with `npm run dist`; the generated files appear under `release/`.

## Highlights

### Capture health you can act on

The live recorder now separates microphone, app/system audio, and recording-file health. Instead of a generic “No audio detected” warning, it explains which path is silent or whether the output file has stopped updating. The row also shows a short startup check, reports what was captured after stopping, and offers an explicit restart using **All system audio** when an app-specific source is unavailable.

### Recording recovery without rewriting originals

Interrupted, orphaned, finalized-but-unindexed, and partially captured sessions now appear in a Recovery inbox. Each item includes its source, capture time, duration, file size, and reason. You can:

- recover the valid primary file;
- recover a usable microphone-only or app-audio stem;
- trim and recover a bounded copy;
- reveal the original in Finder; or
- dismiss the item.

Recovery is non-destructive and idempotent: original files are never rewritten, and successfully cataloged recordings become normal pending meetings.

### One “Needs attention” queue

The Library now consolidates capture/recovery warnings, failed processing, meetings waiting for speaker review, and pending recordings. Items are ordered by urgency and age and include a direct next action. The panel disappears when there is nothing to do.

### Faster, safer speaker review

Speaker rows now distinguish **Unknown**, **Probably <name>**, and **Confirmed**, with confidence, speaking duration, and impacted transcript-line counts. Existing short samples and ranked suggestions remain available. Select several voices and assign them to one roster person in one pass, with a preview of how many transcript lines will change before the merge is applied.

## Additional improvements since the previous README release documentation

- Added a five-minute quiet-capture watchdog and retry behavior around recordings that finalize late.
- Moved built-in recordings into the Library storage flow and added storage diagnostics.
- Added Recently deleted with restore/purge retention, bulk delete, sort controls, week picking, and remembered window bounds.
- Added two-step stop confirmation, a dock `REC` badge, app/native meeting detection, URL-scheme triggers, and a permanent pipeline status bar with learned stage estimates.
- Added global search across titles, summaries, and transcripts, sticky audio playback, transcript seek, speaker colors, summary edit protection, and richer action-item editing.
- Added action-item provenance and fast re-extraction from an edited summary.
- Added reasoning-model badges, canary health checks, thinking suppression, automatic re-sampling, and safer weekly narrative/theme generation.
- Hardened onboarding and packaged-app discovery for Whisper, ffmpeg, LM Studio, Ollama, Hugging Face tokens, and the bundled pyannote sidecar.

## Upgrade notes

- Requires macOS 14.2+ on Apple Silicon.
- Existing meetings and recordings remain in place; database migration 15 adds only recovery-dismissal state and runs automatically on launch.
- Grant both Microphone and Screen & System Audio Recording permissions to use the built-in recorder.
- A local LLM runtime is still required for summaries: LM Studio, Ollama, or another configured OpenAI-compatible endpoint.
- Accept the three pyannote model licenses and provide a Hugging Face read token for first-time diarization setup; cached models run offline afterward.

## Build locally

```bash
git clone https://github.com/dbbaskette/MeetingNotes.git
cd MeetingNotes
git checkout v1.10.0
npm install
npm run dist
```

The installer artifacts are generated at `release/MeetingNotes-1.10.0-arm64.dmg` and `release/MeetingNotes-1.10.0-arm64-mac.zip`.
