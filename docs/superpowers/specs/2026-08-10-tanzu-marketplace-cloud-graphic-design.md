# Tanzu Marketplace Cloud Graphic Design

## Goal

Create a polished, high-resolution PNG of the Tanzu Marketplace cloud scene using `_Marketplace_after.png` as the base and the supplied higher-quality service logos.

## Output

- PNG at the source canvas size of 2730 × 1536 pixels, exceeding the requested 1080-pixel minimum.
- Non-destructive output saved as a new file in the project workspace.
- Preserve the existing illustrated people, desks, monitors, cloud shell, background network motif, and `TANZU MARKETPLACE` heading.

## Marketplace Layout

Rebuild the service area inside the cloud as a balanced 4–4–3 grid. Each service uses a consistent white circular badge, its supplied logo centered without distortion, a dark navy label, and subtle mint connector lines.

Logo order, left to right:

1. PostgreSQL, Valkey, RabbitMQ, MySQL
2. GemFire, Kafka, Data Flow, MCP gateway
3. API gateway, Data Services Manager, AI models

Long labels may wrap to two lines while remaining centered and legible.

## Fidelity Constraints

- Use the supplied logo artwork rather than synthesized approximations.
- Preserve logo colors, aspect ratios, and recognizable silhouettes.
- Keep all text exactly as specified above.
- Do not redraw or materially alter the rest of the illustration.
- Avoid cropped badges, overlaps, misspellings, watermarks, and low-resolution logo edges.

## Production and Verification

Use the approved hybrid workflow: preserve the base illustration, rebuild the cloud interior, and composite the supplied marks. Inspect the final image at full size to verify dimensions, label accuracy, logo placement, edge quality, and that all 11 services are present.
