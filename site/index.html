01 — The thesis

Capture, speech and notes, on this Mac.

MeetingNotes is an Electron app with two Swift helpers. One records. The other transcribes and separates the speakers; it runs only for its operation and then exits. Only the LLM that writes the notes runs as a server: MeetingNotes can start LM Studio or Ollama on demand and stop it after ten idle minutes, or use a server you run yourself.

Core Audio tap

Capture

A signed Swift helper records any app's audio and your microphone into one mixed M4A, with separate microphone and app-audio stems.

Apple SpeechTranscriber

Transcribe

On-device macOS speech-to-text with word timestamps. macOS manages the language assets.

SpeakerKit

Separate voices

Argmax SpeakerKit OSS works out who spoke when and supplies the voice samples used to suggest names. About 11 MB of pinned, verified models.

Your LLM

Any chat model in LM Studio or Ollama writes the notes and extracts the action items.

◈ Boundary Audio, transcripts and notes stay in ~/Documents/MeetingNotes. Speech setup downloads Apple language assets and the public speaker models once, with no account or token; meeting audio is not uploaded. Exports, a remote LLM endpoint or a synced vault send data out only if you set them up.
02 — Signal chain

From waveform to action items.

Transcription and speaker separation run in parallel on the same recording, or one after the other for a meeting of an hour or more to save memory. If a voice needs review, processing pauses so you can name it, and the names go into the transcript before the LLM sees it.

04 — Bring your own model

Reasoning models, handled.

Some local models think before they answer, and occasionally spend their whole token budget without writing a word. MeetingNotes labels known reasoning models, runs a quick extraction check on the one you pick, strips the <think> blocks, and re-samples when a model returns nothing instead of failing the meeting.

05 — Get running

Build it from source.

GitHub releases publish source and release notes without binary installers. Build from source as below, or create a local DMG/ZIP with the packaging instructions. Source builds need Node 22 and Xcode 26+ with the macOS 26 SDK; an installed app needs neither.

~/Projects/MeetingNotes — zsh
# clone and enter
git clone https://github.com/dbbaskette/MeetingNotes.git
cd MeetingNotes

# media inspection, sample playback and recovery
brew install ffmpeg

# source setup (requires Xcode 26+ / macOS 26 SDK), then launch
./scripts/setup.sh
npm start
